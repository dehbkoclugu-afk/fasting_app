# Wow Fasting Experience Design

## Scope

Turn the reliable fasting timer into a distinctive, supportive daily product.
All personalization stays local and uses existing timer, water, streak, and
history data. Copy remains educational and avoids medical diagnosis.

## Experience

- The active timer shows a living ring, a 24-hour arc, metabolic milestones,
  contextual weather, and a focused final-hour state.
- A crisis flow helps the user pause, hydrate, breathe, and delay a decision.
- Completion produces a collectible seal and a replay summary.
- A private local circle provides a shared goal and lightweight support.
- Reports explain trends as a story instead of only exposing charts.
- Water, typography, motion, color, haptics, and state transitions share one
  restrained visual language with accessibility fallbacks.

## Constraints

- No new backend, account requirement, or medical claim.
- No new package unless the installed Flutter/platform APIs cannot cover it.
- Existing session reliability and user changes must remain intact.
- Motion is brief, state-driven, and disabled when accessible navigation is on.

## Delivery

Implement as small reusable widgets and screens attached to the existing timer,
explore, stats, completion, water, router, and theme surfaces.
