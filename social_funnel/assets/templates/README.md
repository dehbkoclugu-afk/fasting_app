# FastTrack campaign artwork

The four images in `../artwork/` were generated with ChatGPT image generation for this campaign. They contain no localized copy; the renderer places reviewed TR, EN, and PT-BR text at export time. Day ranges map to awareness (1–7), activation (8–14), habit (15–21), and trust/conversion (22–30). Source artwork can be replaced with reviewed images using the same filenames. Text rendering uses Windows Segoe UI and FFmpeg is needed only for videos.
