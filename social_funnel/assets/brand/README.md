# FastTrack brand assets

- `fasttrack-avatar.png`: opaque square avatar for Instagram, Facebook, TikTok,
  and Threads. The centered mark is safe for circular crops.
- `fasttrack-mark-transparent.png`: transparent master mark for layouts and
  future cover artwork.

The mark represents a fasting timer, steady progress, and forward movement.
Use the same avatar across all locales. Do not add medical symbols or weight-loss
claims to the mark.
